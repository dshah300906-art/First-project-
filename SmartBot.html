Quick Configuration

Visual .env Generator

Generate your deployment config file in real-time. Just select a bot and fill in key details to compile your secure environment variables.

Parameters

config.env 
# AI RAG PDF Chatbot Configuration
TELEGRAM_BOT_TOKEN=
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=

# LLM Routing Setup
LLM_PROVIDER=openai
LLM_MODEL=gpt-4o-mini

# RAG Splitting Parameters
CHUNK_SIZE=1000
CHUNK_OVERLAP=200
RETRIEVER_K=5
ℹ️ Copy this output, save it as config.env in the bot's root directory, and launch.
Deployment

Ready in Minutes

Spin up any bot using Docker Compose in a single terminal command. Zero global dependencies required.

01

Configure Environment

Generate and paste your variables into the config file within the specific bot folder:

cp config.env_sample config.env
02

Launch via Docker

Navigate to the bot subdirectory and run the container system locally:

docker-compose up --build -d
03

Validate Telegram

Message your bot on Telegram and run the start script to verify functionality:

/start
